# UI-UX-restaurant-reservation-
## Lavender & Pink Dine In — UI/UX Project Overview
A boutique restaurant discovery and reservation platform UI/UX design featuring an elegant lavender and rose-gold aesthetic.

Design Systems & Assets
Color Palette: Soft Lavender (#D8D4F2), Blush Pink (#FFD1DC), Warm Copper/Gold, and Crisp White.

Typography: Decorative Calligraphy/Script for headings & brand statements; standard Sans-Serif for functional input fields and navigation text.

Component Library:

Top navigation header with brand logo, central search bar, and user profile action.

Interactive restaurant cards featuring thumbnail preview, star ratings, information action, and direct reservation triggers.

Reservation modal card displaying venue details, dynamic date/time selections, guest counts, and table placement options.

Universal footer containing quick links (About Us, Contact Us, Service & Policy).

User Flow & Core Screens
1. Landing Screen (landing_screen)
Hero Branding: Features the primary brand tagline "Cultivated Flavors, Timeless Moments."

Quick Reservation Widget: Allows users to input booking parameters directly from the landing page:

Select Day / Date

Select Time Slot

Specify Party Size (Number of People)

Select Target Restaurant

Search Access: Prominent central search bar for quick query entry.

2. Home Page (home_page)
Restaurant Discovery Carousel: Horizontal scrollable grid presenting curated dining venues (e.g., L'Étoile Floral, Rosewood & Thyme, The Copper Garden, Aura Patisserie).

Card Data Features:

High-quality culinary cover imagery.

Dynamic star rating indicators (e.g., 4.3 ★).

Secondary action button (Info) and primary action button (Reserve).

Pagination Bar: Visual indicator for scroll position across venue options.

3. Checkout Modal (checkout)
Reservation Summary Overlay:

Selected restaurant thumbnail and venue title (Rosewood & Thyme).

Confirmed date (Sept 12, 2026), time (7:30 PM), guest count (2 People), and table allocation (Table: Patio - T4).

Actions: Secondary Cancel button and primary Checkout trigger.
